# PaperFlow v0.3

Local-first PySide6 literature/reference manager.

## Run
```bash
uv sync
uv run paperflow
```

## v0.3
- GitHub-ready uv/src layout and VS Code/test configuration
- PDF indexing, DOI/Crossref metadata, SQLite notes and summaries
- Ask AI without API: relevant local-PDF context → prompt → clipboard → ChatGPT/Claude/Gemini
- CSL citation rendering using citeproc-py
- APA 7th, Vancouver, Nature, IEEE, AMA, Cell, Science, The Lancet, European Heart Journal, Circulation
